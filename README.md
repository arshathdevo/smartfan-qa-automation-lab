# SmartFan QA Automation Lab

An end-to-end software quality engineering project that combines a simulated Smart Fan application, REST API, automated testing framework, and AI-powered troubleshooting evaluation.

## Project Overview

SmartFan QA Automation Lab is an independent educational project designed to demonstrate modern software testing and AI quality engineering practices.

The platform simulates a smart ceiling fan with features such as power control, speed adjustment, operating modes, temperature monitoring, and energy consumption tracking.

A troubleshooting assistant will provide an additional layer for evaluating AI-generated responses.

## Key Features

- Smart fan power control (ON/OFF).
- Six-level fan speed adjustment.
- Sleep, Normal, and Boost operating modes.
- Simulated temperature monitoring.
- Energy consumption monitoring.
- AI-powered troubleshooting assistant.

## Quality Engineering Scope

- Reusable test automation framework.
- Web UI functional and regression testing.
- REST API validation.
- AI response quality evaluation.
- Hallucination and prompt injection testing.
- Test reporting and continuous integration.

## Project Architecture

The application will consist of a frontend, backend REST API, and a dedicated automated testing framework.
